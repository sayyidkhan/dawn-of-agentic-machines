# VERTICAL SLICE BUILD PLAN

## Milestone 1 — Greybox Hunt

Goal: prove controller and combat loop.

Deliverables:

- third-person movement
- controller input
- dodge
- light/heavy attacks
- dummy enemy
- health/stamina
- one greybox arena

Exit condition:

Fighting a stationary or simple moving target already feels responsive.

## Milestone 2 — Monster Prototype

Deliverables:

- monster locomotion
- 4 attacks
- phase state
- damage zones
- stagger
- death

Exit condition:

Player can complete a basic boss fight.

## Milestone 3 — Hunt Structure

Deliverables:

- tracking clues
- monster roaming
- first retreat
- secondary arena
- nest
- reward screen

Exit condition:

The experience feels like a hunt, not an arena boss demo.

## Milestone 4 — Combat Polish

Deliverables:

- input buffering
- hit stop
- camera impulses
- impact VFX
- part breaking
- improved monster telegraphs
- controller rumble

Exit condition:

Players can explain why hits feel satisfying.

## Milestone 5 — Visual Pass

Deliverables:

- final terrain
- vegetation
- lighting
- fog
- water
- vistas
- monster materials
- cinematic atmosphere

Exit condition:

Screenshots look like a premium action RPG prototype.

## Milestone 6 — UI/UX Pass

Deliverables:

- exploration HUD
- combat HUD
- Hunter Sense
- inventory/equipment screen
- pause/settings
- controller glyph switching

Exit condition:

UI supports the world without dominating it.

## Milestone 7 — Playtest

Test for:

- control confusion
- camera frustration
- dodge spam
- unreadable attacks
- unfair damage
- excessive HUD
- hunt pacing

Prioritize fixes that affect feel over adding content.
