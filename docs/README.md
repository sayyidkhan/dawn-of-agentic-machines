# Project Chimera — Single-Player Hunting RPG

A focused single-player action RPG prototype inspired by the deliberate hunt loop of Monster Hunter and the clean, cinematic UI/UX philosophy of Horizon Zero Dawn.

This repository pack is intentionally scoped as a vertical slice:

- 1 playable hunter
- 1 weapon archetype
- 1 large monster
- 1 handcrafted hunting region
- 1 complete hunt loop
- controller-first input
- Unreal Engine 5 target

## Product Goal

Create a 20–30 minute polished hunting experience that proves:

1. Weighty, readable melee combat
2. Monster behavior that feels alive rather than scripted
3. Exploration and tracking before combat
4. High-end environmental presentation
5. Controller-first playability
6. A restrained, cinematic HUD

## Recommended Tech

- Unreal Engine 5
- Enhanced Input
- Gameplay Ability System optional for later scale
- Behavior Trees + StateTree for monster AI
- Motion Warping
- Control Rig / IK Rig
- Niagara
- MetaSounds
- Lumen
- Nanite
- World Partition optional; not necessary for the first region
